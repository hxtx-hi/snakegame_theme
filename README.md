## 介绍

主题中的背景来自米游社。游戏支持从 GitHub 或 Gitee 官方仓库一键加载精选主题。

## 项目结构

```
snakegame_theme/
├── index.html         # 游戏本体（直接用浏览器打开即可运行）
├── themes/            # 官方主题文件
│   ├── 哥伦比娅.json   # 哥伦比娅风格
│   ├── 柯莱.json       # 柯莱风格
│   └── 温迪.json        # 温迪风格
└── README.md
```

## 安装教程

1. 下载 `index.html` 文件
2. 用浏览器打开即可运行

## 使用说明

1. 游戏很简单，打开的都会用
2. 游戏里的官方主题仓库就是本仓库
3. 在设置 → 风格装扮 → 官方主题列表中，可选择从 GitHub 或 Gitee 加载主题
4. 内置豆包主题生成提示词，可以在复制粘贴间一键生成
5. 点击设置旁的 👤 按钮可访问作者主页
